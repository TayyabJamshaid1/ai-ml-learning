What is pass in Python?
pass is a placeholder statement that does absolutely nothing. It's used when Python requires a statement syntactically but you don't want to execute any code.


The Problem Without pass:

class Student:
    def __init__(self):
        # Python expects something here!
        # If empty, it will give an error

# ❌ SyntaxError: unexpected EOF while parsing


The Solution: Using pass

class Student:
    def __init__(self):
        pass  # ✅ Does nothing, but satisfies Python's syntax

s1 = Student()

Benefits:
1. Placeholder for Future Code
def calculate_grade(marks):
    pass  # I'll write this function later

def validate_student(student):
    pass  # TODO: Implement validation

    
2-You can use it in Empty Classes/Functions

class Student:
    pass  # Empty class is valid with pass

class Teacher:
    pass

# Later, you can add methods
class Student:
    def __init__(self, name):
        self.name = name

3-In Loops/Conditionals

for i in range(10):
    if i % 2 == 0:
        pass  # Do nothing for even numbers
    else:
        print(i)  # Print odd numbers
