Def of Polymorphism(different forms/different meanings):When the same operator is allowed to have different meaning according to the context

Best example of Polymorphism is Overloading

Example
print(2+3)
print("good"+"boy")
print([1,2,3]+[4,5,6])

as see in upper examples,+ has different meaning according to the context.If you talking about int numbers, + will add it,if you talking about strings,+ will concatenate them,if talking about lists,+ will merge them.operator is same but execution are different according to context

        num1.__add__(num2)

See example:

class Complex:
     def __init__(self,real,img):
          self.real=real
          self.img=img

     def showNumbers(self):
          print(f"{self.real}i + {self.img}j")

     def __add__(self,num2): #dunder function
          realData=self.real+num2.real
          imgData=self.img+num2.img
          return Complex(realData,imgData)

     def __sub__(self,num2): #dunder function
          realData=self.real-num2.real
          imgData=self.img-num2.img
          return Complex(realData,imgData)


num1=Complex(3,5)
num1.showNumbers()
num2=Complex(7,7)
num2.showNumbers()

num3=num1+num2
num3.showNumbers()

num4=num2-num1
num4.showNumbers()

now see hum ny yaha pr + and - ka matlab he change kr dia,this is known as operator overloading, isi ko Polymorphism  kehty ha

class Circle:
     def __init__(self,radius):
          self.radius=radius

     def calculateArea(self):
          return 3.14*self.radius*2

     def  calculatePerimeter(self):
          return 2*3.14*self.radius

        self.itemPrice=itemPrice
