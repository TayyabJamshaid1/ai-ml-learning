del keyword:
Used to delete object properties or object itself

Syntax:
del s1.name;
del s1;

Example:
class Account:
      def __init__(self):
            self.balance=20
            self.account_number=20

      
a1=Account()
print(a1.balance)
del a1.balance
print(a1.balance)

Private:
Agr class ka koi b attribute or method hum chahty ha k class k bhr avaiable na hu or kisi obj k liye avaiable na hu tab hum usy private bna lty ha.

Definition:
"Private attributes & methods are meant to be used only within the class and are not accessible from outside class"

=>we can make private by adding two underscore before attribute name __name,it means now it is a private
=>REmember private attributes & methods both are accessible with in class

Example:
class Account:
      def __init__(self,acc_no,acc_pass):
            self.acc_no=acc_no
            self.__acc_pass=acc_pass

      def resetPassword(self):
            print(self.__acc_pass) #accessible with in class

a1=Account(12345,"kesa")
a1.resetPassword()
print(a1.__acc_pass) #cannot accessible outside class

Output:
kesa
Traceback (most recent call last):
  File "/home/tayyab/Documents/AI,ML Learning/first.py", line 11, in <module>
    print(a1.__acc_pass)
AttributeError: 'Account' object has no attribute '__acc_pass'

=>Python k andr hum attribute & methods ko private tu bna skty ha,but ye private jesy hu gy,exactly private ni hu gy
