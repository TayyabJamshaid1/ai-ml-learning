String Slicing
A string in python can be sliced for getting a part of the strings.

Example 1:
df="Tayyab"
sd=df[0:3]   //last index value is not included
print(sd)  #output: Tay   


Example 2:
df="Tayyab"
sd=df[1:4]
print(sd)  #output: ayy

Example 3:
df="Tayyab"
   -6-5-4-3-2-1
 
sd=df[-4:-1]
print(sd)  #output: yya
