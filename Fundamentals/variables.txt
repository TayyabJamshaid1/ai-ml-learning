name = "harry" # identifies name as class <str>

Rules for Choosing an Identifier
A variable name can contain alphabets, digits, and underscores. e.g : hhs@gdg=99 not allowed
A variable name can only start with an alphabet and underscores. e.g 1data=99 not allowed
A variable name can’t start with a digit.
No white space is allowed to be used inside a variable name.
Examples of a few variable names are: harry, one8, seven_, _seven etc.
Wrong syntax: as*sdd=9,a@sdd=87, 8Kesa=88;(special characters except underscore are not allowed)
