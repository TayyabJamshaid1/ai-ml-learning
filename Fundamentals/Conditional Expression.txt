If Else And Elif In Python
If else and elif statements are a multiway decision taken by our program due to certain conditions in our code.

Syntax:
if(condition1): # if condition1 is True
 print("yes")
elif(condition2): # if condition2 is True
 print("no")
else: # otherwise
 print("maybe")

 Problem 3:
Write a program to find out whether a student has passed or failed if it requires a total of
40% and at least 33% in each subject to pass. Assume 3 subjects and take marks as an
input from the user.

 Solution:
 
marksDictionary={}
q=int(input("Enter a marks in physics: "))
marksPhysics=(q/100)*100
marksDictionary.update({"physics":f"{marksPhysics}%"})

q=int(input("Enter a marks in chemistry: "))
marksChemistry=(q/100)*100
marksDictionary.update({"chemistry":f"{marksChemistry}%"})

q=int(input("Enter a marks in math: "))
marksmath=(q/100)*100
marksDictionary.update({"math":f"{marksmath}%"})

total_percentage=((marksPhysics+marksChemistry+marksmath)/300)*100


print(marksDictionary,total_percentage)

if (total_percentage>=40 and (marksmath>32 and marksChemistry>32 and marksPhysics>32)):
    print(f"student has been passed,his percentage is {total_percentage}")
else :
    print("Below than 33%,failed")
