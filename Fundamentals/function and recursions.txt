There are two types of functions in python:
=>Built in functions (Already present in python)
=>User defined functions (Defined by the user)
Examples of built in functions includes len(), print(), range() etc.
The avg() function we defined is an example of user defined function.

Recursion:
Recursion is a function which calls itself.
It is used to directly use a mathematical formula as function.

Example :
def factorial(n):
        if (n==1) or (n==0):
             return 1 #because the factorial of 1 and 0 is by default 1
        return n*factorial(n-1)


a=factorial(5)
print(a)

        if (a>b) and(a>c):
             return f"{a} is greater"
        elif (b>a) and(b>c):
             return f"{b} is greater"

Problem 3:
Write a recursive function to calculate the sum of first n natural numbers.
Solution:
def recur(n):
    if (n==0) or (n==1):
       return 1
    return n+recur(n-1)

res=recur(5)
print(res)

Strip() method removes leading and trailing characters (spaces, tabs, and newlines by default) from both ends of a string. Because Python strings are immutable, it returns a new string copy and does not modify the original data

def removeWord(arr,word):
       unique=[]
       for i in arr:
