Range Function In for loop
The range() function with for in python is used to generate a sequence of number.
We can also specify the start, stop and step-size as follows:
range(start, stop, step_size) 

# by default,if start is not provided,it will start from 0
# step_size is usually not used with range()
# if step_size is provided,it will jump/ignore the provided numbers
Example 1:
for i in range(1,6):
    print(i)

Example 2:
for i in range(6):    # by default start with 0
    print(i)

Example 3:
for i in range(0,6,2):
    print(i,' for loop')

Output :

2  for loop
4  for loop   
#step_size ki logic ye ha k provided value me sy 1 ko minimize kr k iterations ko show krta ha

Break:
it will come out from the loop when condition meets
for i in range(1,50) :
    if (i==20): break    #it will come out from the loop when i is 20
    print(i,' for loop')


--------------------------------------------
Continue:
it will come out from that particular iteration only when condition meets
for i in range(1,50) :
    if (i==20): continue    #it will skip this iteration when i is 20
    print(i,' for loop')

Problem 1:
Write a program to print multiplication table of a given number using for loop.
Solution:

    print (f"2 X {i} = {2*i}")


Problem 2:
Write a program to greet all the person names stored in a list ‘l’ and which starts with S.
l = ["Harry", "Soham", "Sachin", "Rahul"]

Problem 5:
Write a program to find the sum of first n natural numbers using while loop

Solution:
n = int(input("Enter a number: "))

sum=0
for i in range(1,n+1):
    sum+=i


print(sum)

Problem 8:
Write a program to print the following star pattern.
* * *
*   *     for n = 3
* * *
Solution:
n = int(input("Enter a number: "))

for i in range(1,n+1):
    if (i==1 or n==i):
        print("*"*n,end="")
    else:
        print("*",end="")
        print(" "*(n-2),end="")
        print("*",end="")
    print() 

Problem 9:
Write a program to print the following star pattern:
*
**
*** for n = 3

Solution:
n = int(input("Enter a number: "))

for i in range(1,n+1):
    print("*"*(i),end=" ")
    print(" " * (n-i),end=" ")

    print(" ")
