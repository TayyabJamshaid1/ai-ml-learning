Built in exceptions:
There are many built-in exceptions which are raised in python when something goes wrong.

try:
    a=int(input("Enter a number "))
    print (a)

except ValueError as v:
    print("You enter wrong data type data",v)
except Exception as e:
    print(e)

print("Program end")

Other built in exceptions are ZeroDivisionError,TypeError etc

Try With Else Clause
If try run successfully,then else will run
try:
 # Some code
except:
 # Some code
else:
 # Executed if try was successful

 Example:
 try:
    a=int(input("Enter a number "))
    print (a)

except ValueError as v:
    print("You enter wrong data type data",v)
except Exception as e:
    print(e)
else :
    print("i will run if try run successfully")
print("Program end")
