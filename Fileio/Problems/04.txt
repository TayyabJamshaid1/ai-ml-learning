
Write a program to generate multiplication tables from 2 to 20 and write it to the different
files. Place these files in a folder for a 13-year-old

for j in range(2,20):
    with open(f"practice{j}.txt",'a') as f:
         for i in range(1,11):
              f.write(f"\n{j}*{i}={j*i}")

The game() function in a program lets a user play a game and returns the score as an
integer. You need to read a file ‘Hi-score.txt’ which is either blank or contains the previous
Hi-score. You need to write a program to update the Hi-score whenever the game()
function breaks the Hi-score.


import random
def checkScore():
    print("You are playing the game")
    score=random.randint(1,62)
    with open("practice.txt") as f:
          hisScore=f.read()
          if(hisScore!=""):
             hisScore=int(hisScore)
          else:
              hisScore=0
    print(f"Your score {score}")
    if (score>hisScore):
        with open("practice.txt","w") as f:
             f.write(str(score))
             print("You win")
    else:
        print("You loose")
    return score


print(checkScore())

A file contains a word Doggh & yuu multiple times. You need to write a program which
replaces this word with ##### by updating the same file.


words=["yuu","Doggh"]

with open("practice.txt") as f:
    content=f.read()
    for i in words:
        content=content.replace(i,"#" * len(i))

    with open("practice.txt","w") as f:
         f.write(content)
