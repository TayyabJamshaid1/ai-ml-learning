9-w+
#it is open for reading and writing. The file is created if it does not exist otherwise it remove all the content of file.The Pointer is positioned at beginning of the file

f=open("verify.txt","w+")
data=f.read() 
print(data) #it will show empty because w+ remove all the content from it and pointer is positioned at the end of file
f.write("kesa")#it will write new content "kesa"
f.close()

Imp Scenario:
f=open("verify.txt","w+")

f.close()

10-a+
#it is open for reading and writing.if verify.txt does not exist,append will create it automatically.The Pointer is positioned at end of the file

f=open("verify.txt","a+")
f.write("kesa")
data=f.read() # kesa will be appended at the end of file
print(data) #it will print empty because a+ mei pointer file k sab sy last pr huta ha
f.close()


Summary:
r+  read + override (Pointer is at start) no truncate(data will not removed)
w+  read + override (Pointer is at start)  truncate(data will  removed)
a+  read + append   (Pointer is at last)  no truncate(data will not removed)
#w override the content while append add content at last of file
