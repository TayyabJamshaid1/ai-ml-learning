=>The ram(random-access memory) is volatile, and all its contents are lost once a program terminates. In order to persist the data forever, we use files.
=>Python can be used to perform operations on a file (read & write file)
=>A file is data stored in a storage device. A python program can talk to the file by reading content from it and writing content to it.

Type Of Files.
There are 2 types of files:
1. Text files (.txt, .c, etc)
2. Binary files (.jpg, .dat, etc)
Python has a lot of functions for reading, updating, and deleting files.
