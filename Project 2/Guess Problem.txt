Project 2 : The Perfect Guess
We are going to write a program that generates a random number and asks the user to
guess it.
If the player’s guess is higher than the actual number, the program displays “Lower
number please” .
Similarly, if the user’s guess is too low, the program prints “Higher number please” .
When the user guesses the correct number, the program displays the number of
guesses the player used to arrive at the number.

Solution:

import random

score=random.randint(1,10)

randomGuesses=0
inputData=1

while (inputData!=score):
       inputData=int(input("Enter Your Number : "))
       if (inputData>score):
              print("Your Guess number should be low")
       elif (inputData<score):
              print("Your Guess number should be high")
       elif (inputData==score):
              print(f"Your Guess number is now equal,actual correct number is {score},your attempts are {randomGuesses}")
       randomGuesses+=1
