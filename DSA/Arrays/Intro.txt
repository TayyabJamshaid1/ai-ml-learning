Abstract Data Type:
Abstract data type is basically a blueprint which tells us the minimal requirements along with operations. e.g let sppose ,mjy ek pc bnana ha ,pc bnany k liye jo minimal requirements jo ho gi wo ha ram,cheap,engine etc,agr ye chezain pori hu gi tu hum khud sy pc build kr ly gy aur pc pr hum multiple operations perform kary gy like gaming etc.

In real,Best example of Abstract data type is array,array me hamari minimal requirement srf 2 ha (ek,item ko get krny ka method aur second us k andr item add krny ka method) ,baqi us k upr hum multiple operations perform kr skty ha e.g insert,delete,update. Hamri minimal requirements ko hum hamesha Abstract he rkhty ha aur user ko kahay gy k tm srf methods ko use kro,pichay kya functionality ha usk upr mat jao (See Array as Abstract Data Type.png) image

Array cannot be risize,let suppose apny 10 elements ki array "man" bnai aur k bad apny us program ya kisi aur program me koi aur arrays wagaira bnai,ab "man" array k sath jo avaiable space thi wo kisi aur ny occupied kr li,ab "man" array k sath wali space occupied ha,is liye hum usy resize ni kr skty although hum ek new big array bna k "man" array k elements us me copy kr skty ha

Arrays is the first Data Structure.To store a multiple data,we use a array.In array data structure, we store the each data in individual block.Is k har ek block me kuch na kuch information store ha.Is pori array ka ek he nam hu ga jis k zariye hum data ko track kary gy

Properties of array:
1-We can store  the same datatype of data in array,e.g no string & int together etc,agr hum integer store krwa ha tu sab me integer he store hu ga

2-Arrays are contigous in memory(sab data ek sath memory me store huta ha)

3-Array are also known as linear(straight line structure)

Syntax:
int marks[5] #we make a 5 blocks,har block ek integer jitni space occupied krta ha jis me hum different integer store krty ha.Ye sary blocks ek sath memory me store huty ha
