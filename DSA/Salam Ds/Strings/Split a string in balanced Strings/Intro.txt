
My Solution:
let str="RLRRRLLRLL",count=0,R=0,L=0

for (let i=0;i<str.length;i++){
  if (str[i]=="L"){
    ++L
  }else if (str[i]=="R"){
    ++R
  }
  if (R==L){
    R=0;
    L=0
    ++count
  }
}
console.log(count)


Recommended Solution:

let str="LRRRRLLRLL",count=0,temp=0;

for (let i=0;i<str.length;i++){
  if (str[i]=="R"){
    ++temp;
  }else if (str[i]=="L"){
    --temp
  }
  if (temp==0){
   temp=0
    ++count
  }
}
console.log(count)
Time complexity is O(n) and space complexity is O(1)
If every time,you have to balance something,and that is binary problem like this then allways think about +1,-1 solution
