Now,in our problem,we have to work according to k,k is a integer.
let suppose, k=2,then 2k=4(make it double if k double),now assume,you are given a string ,str="abcdefghijk",now you have to divide it according to 2k which is 4 ,so it becomes    abcd  efgh ijk ,now you have to reverse only k elements to each other,means k=2 ,in each pair abcd,only reverse first 2 elements bacd,in pair efgh ,only reverse first 2 elements fegh,in pair ijk, only reverse first 2 elements jik.
So my solution is  below


let str="abcdefghijk",k=2;

let s=str.split("");
for (let i=0;i<s.length;i+=k*2){  //2k steps chor du per iteration
   let mid=Math.floor(k/2)
    for (let j=0;j<mid;j++){  //per iteration/step mei kitny elements ko swap krna ha 
        let temp=s[i+j]
        s[i+j]=s[i+k-1-j]
        s[i+k-1-j]=temp
    }

}
console.log(s.join(""))

------------------------------------------
Time complexity is seen to be O(n^2) but in reality it is O(n) because we do not iterate on each element,we skip 2k elements and also reverse only a k part,thats why it is O(n)

Space complexity is O(n) because you are creating a array of  n number of string by str.split("") because in js & other languages,string is immutable ,you have to convert it in array to change its location,but in some languages,strings are mutable,for that languages ,space complexity is O(1)
