Anagram is a jumping/shuffling/re arranging of letters,basically you are mixing up these letters and make another word that is known as anagram.
Anagram Examples:

Example 1 
wordOne=Anagram
wordTwo=nagaram
In example 1,all are anagram

Example 2
wordOne=Tayyab
wordTwo=yatbay
wordThree=yyatab
In example 2,all are anagram

Example 3:
wordOne=cat
wordTwo=rat
In example 3,wordTwo are not anagram

all the letters that you see over wordOne are present over on wordTwo exactly once .In short,the size of wordOne and wordTwo should be same.If size are different,it means some words are missing,that is not anagram

One solution to check that both strings is anagram or not is that we sort both strings alphabatically and then compare its values.For a sorting purpose,In Js and java,strings are immutable while in some languages it is mutable .We do not directly sort or replace strings,we first have to create a array of it.For this Js and java behaviour,its space complexity is O(n) because we are coneverting the string into array,those languages where strings is mutable ,their space complexity is O(1) and time complexity is O(nlogn)
