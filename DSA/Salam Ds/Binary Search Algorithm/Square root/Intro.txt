We never recommend brute force approach,so we have to move on another solution.Another recommended solution is Binary Search Solutions.
In this approach,we have take first value as left and last value as right,then calculate middle value of it. m=(l+r)/2.

assume, x= squareRootValue
If m>x,then left remain same,right become r=m-1
If m<x,then right remain same,left become l=m+1

var mySqrt = function(val) {
    if (val<2) return val
        let l=2,r=Math.floor(val/2),m=0;
while(l<=r){
m=Math.floor((l+r)/2)
if (m*m===val){
    return m
}else if(m*m>val){
r=m-1
}else{
l=m+1

}
}
return r;
