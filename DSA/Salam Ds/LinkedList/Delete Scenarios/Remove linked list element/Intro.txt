When i have to delete any node in linked list,i need to keep a track of previous node also.Without keeping a track of previous element,we cannot delete any thing.So here comes  a new concept "Sentinel node".Sentinel node will keep a watch/check on next element/node.This sentinel node will act like a previous element and will keep a check on next element.

So sentinel node is a dummy node,we dont care about the value of  sentinel node but this is the node that will add on front of list.Now this node will keep a check on next element.So ,sentinel node will becomes our previous node.It helps us delete nodes from starting indexes .
