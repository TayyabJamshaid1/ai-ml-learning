"Function calls itself to solve smaller version of same problem"

Two Parts of Recursion:
1-Base case -  Stop Condition (When to stop calling itself) 
2-Recursive case - part where function calls itself

See Intro image

Generally,In recursion we have to pay focus on base case because base case will decide when will recursion stops.See (Recursion base case example image)

Whenever we will write recursion code, most of the time we write  base case on  top of the program.Allways make sure your base case is written on the top and it actually stops the recursion else it will go on infinite loop

As soon as the recursion is happening,it is continuously pushing the functions in call stack.See Recursion CallStack.png.So if the recusion is infinite loop,then call stack is pushing functions continuously inside it.Now this call stack in this situation is known as "Stack Overflow".It becomes hang and stop working

"Infinite Recursion leads to stack overflow"

Imp:
Allways keep in mind,whenever you are printing numbers 1....n,using recursion or for loop,its time complexity will be O(n).See Common Mistakes image
