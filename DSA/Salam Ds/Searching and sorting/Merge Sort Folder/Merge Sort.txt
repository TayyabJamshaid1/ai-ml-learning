Merge Sort:(Divide & conquer algorithm)

It says if given an array,suppose having 8 elements in it,we will keep dividing an array in 2 halfs.Then each part divided into two half,then that each part is divided into two halfs till my array elements become singular & individual then we will merge them in a sorted way.(Same process like recursion).We will merge it in a sorted way while going back

So Merge sort is implemented in 2 parts
1-Divide Phase
2-Merge/conquer Phase

function merge(left,right){
     let mergeResult=[],i=0,j=0;
  while(i<left.length && j<right.length){
        if(left[i]<right[j]){
          mergeResult.push(left[i])
          i++
        }else{
           mergeResult.push(right[j])
          j++
        }
  }
  return [...mergeResult,...left.slice(i),...right.slice(j)]
}

function merge(left,right){
     let mergeResult=[],i=0,j=0;
  while(i<left.length && j<right.length){
        if(left[i]<right[j]){
          mergeResult.push(left[i])
          i++
        }else{
           mergeResult.push(right[j])
          j++
        }
  }
  return [...mergeResult,...left.slice(i),...right.slice(j)]
}

function mergeSort(arr){
  if (arr.length<=1) return arr; //base condition
  let mid=Math.floor(arr.length/2)
  let left =mergeSort(arr.slice(0,mid))
  let right =mergeSort(arr.slice(mid))
  return merge(left,right)

}
let result=mergeSort([2,8,6,7,5,1,3,9,10])
console.log(result)

----------------------------------------- Time Complexity
As we know merge sort has 2 parts
1)Divide
This part time compexity is O(log2n)

2)Conquer/merge
This part time compexity is O(n)

Comparing them,the time complexity of merge sort is O(nlog2n)
MUch better/faster/efficient then selection,insertion & bubble sort because their time complexity is O(n^2)
